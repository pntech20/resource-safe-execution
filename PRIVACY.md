# Privacy

## Skill runtime

Resource Safe Execution itself performs no network access and collects no telemetry.
The skill runs locally and does not send task content, probe output,
or system details to this project.

## Optional installer

The optional third-party skills CLI records anonymous, opt-out install
telemetry for skills.sh. That installation behavior belongs to the `skills` CLI,
not the Resource Safe Execution skill runtime. Review the CLI's documentation
and privacy information before choosing to use it.

## Other services

GitHub, OpenAI, Anthropic, Google, and social platforms apply their own privacy
policies when you access those services. This project does not control those
services or their data practices.

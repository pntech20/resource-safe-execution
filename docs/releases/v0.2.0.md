# Resource Safe Execution v0.2.0

v0.2.0 is a packaging and distribution release for the existing audited
skill.

## Highlights

- Adds Codex and Claude plugin metadata around the canonical skill folder.
- Adds verified launch visuals, safety case studies, and community intake
  templates.
- Publishes a release-pinned install route for the distribution package.

## Runtime and compatibility scope

The canonical nine-file skill payload is unchanged from v0.1.0, including the
probe, safety policy, JSON schema, `skill-manifest.json`, and `SHA256SUMS`.
No new client-runtime compatibility claim is made by this release.

## Audited install

```powershell
npx --yes skills@1.5.20 add https://github.com/pntech20/resource-safe-execution/tree/v0.2.0/skills/resource-safe-execution --skill resource-safe-execution --copy
```

Verify the installed paths against the attached `skill-manifest.json` and
`SHA256SUMS`.

## Validation

The release is gated by the repository test suite, both bundled skill
validators, the plugin package validator, and the six-job Windows, macOS, and
Ubuntu CI matrix on Python 3.10 and 3.13.

# Support

Choose the route that best fits your request:

- For a reproducible bug, open the [bug report form](https://github.com/pntech20/resource-safe-execution/issues/new?template=bug_report.yml).
- For compatibility evidence from a real task, open the [compatibility report form](https://github.com/pntech20/resource-safe-execution/issues/new?template=compatibility_report.yml). A compatibility report is evidence, not automatic support.
- For usage questions, ideas, or general discussion, use [GitHub Discussions](https://github.com/pntech20/resource-safe-execution/discussions).
- For security vulnerabilities, use [private security advisories](https://github.com/pntech20/resource-safe-execution/security/advisories/new). Do not disclose vulnerabilities in public issues or discussions.

Please redact secrets, personal data, and private task content from anything you
submit publicly.
